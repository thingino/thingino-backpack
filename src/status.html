Addresses

Console

The serial console, raw, one client at a time; a new one takes over. Ctrl-] leaves.

RFC 2217, for tools that set the baud rate or send a break, on the camera SoC's UART. Its DTR holds the boot pin and RTS cuts the power, as esptool's auto-reset does.

Terminal

closed

Each UART is also on its own TCP port, raw: connecting here takes it over from socat, and socat takes it back the same way. Click the terminal to type; Ctrl-C over a selection copies it.

Flash chip

idle

The flash programmer is off: UART 2 and 3 use the clip's pins. Set the UARTs back to 1 in Settings to use it.

The camera's SPI flash through a SOIC-8 clip, for flashrom 1.4.0 or later.

VCC From the backpack needs the camera off. From the camera is for boards whose flash shares the SoC's rail: each run power-cycles the camera with the boot pin held, so its bootrom leaves the flash alone.
HOLD Chips in quad mode ignore HOLD, so it can be left alone for them.

UARTs

Up to three consoles, for a camera with more than one chip to watch: the SoC, a battery or motor MCU, a Wi-Fi chip. UART 2 and 3 use the flash clip's pins, so turning them on turns the flash programmer off; UART 3 also takes the backpack's own log UART. Changing the number restarts the backpack.

Camera

BOOTSEL For boards that bring out the SoC's boot select. It moves with the boot pin; driven high only while the camera is powered.
USB port Disconnected powers the port down and lets go of the lines, for a camera whose SoC hosts a USB Wi-Fi module on them. Entering the bootrom needs it connected.
